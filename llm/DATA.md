# 数据、标注与隐私说明

## 语料

| 项 | 值 |
|---|---|
| 来源 | MiniMind 预训练语料 `pretrain_hq.jsonl` |
| 格式 | JSONL，每行 `{"text": "..."}` |
| 字段 | `data.text_field = "text"` |
| 使用量 | 前 100 MB 子集 |
| 切分 | `block_size=128`，训练/验证 98/2 |
| 训练 token | 20k 步 × 512 token/步 ≈ 10.24M |
| 仓库是否包含 | **否** |
| 配置路径 | `data/minimind/pretrain_hq.jsonl`（相对路径） |

语料不进入 git；`data/` 已在 `.gitignore` 中。使用者需自行从 MiniMind 上游
获取，并遵守其许可证。仓库不重新分发语料，也不对语料的完整性、许可证或
PII 状态作保证。

## 标注

本工作没有人工标注：

- 训练目标是自监督 next-token cross entropy；
- 文档之间插入 EOS；stage2 起加入 BOS；
- EOS/BOS 使用加权 CE（权重 4/2），只改变损失权重，不改变标签；
- 没有指令/对话标注，因此模型不是 chat model；
- 没有做数据清洗、去重、PII 过滤或毒性过滤。

## 数据伦理

- 语料是通用中文预训练文本，未做 PII 审计；模型可能记住或生成敏感内容。
- 不应把模型用于个人画像、医疗、法律、招聘等高风险决策。
- 采样结果只用于研究展示；报告中的 `你好` 输出不代表模型理解或可靠性。
