# 今日实验复盘：暴露了什么问题（2026-10-29）

## 0. 一句话

今天暴露的核心不是「引擎算错了」，而是三件事：
**学习规则缺少稳态与信用分配机制**、**评测口径容易被误用**、
以及**我在方法上多次用错工具**（用 BPTT 的模型论证局部规则、用批量近似论证精确性）。

---

## 1. 方法论问题（我的错误，可复现的教训）

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1.1 | 用 BPTT 训练的脑论证多巴胺机制 | 归因无效：梯度下降的收益被算到局部规则头上 | 区分「监督拟合」与「脑的学习方式」；`docs/architecture.md` 已写明两者不同 |

## 2. 框架/引擎层面的缺陷（有实测数据）

### 2.1 没有稳态：默认尺度下三因子规则是「惰性」的

`weight_scale=0.18`（项目默认）时，跑 2000 个样本后：

| 指标 | 值 |
|---|---|
| 脑区状态均值 | 0.018 |
| eligibility 最大值 | 0.0074 |
| 单次权重变化 | ≈ 2e-6 |
| 权重范数 | 5.150 → 5.150（**完全没变**） |

规则名义上在跑，实际没有产生任何学习。**引擎没有任何机制把活动/权重自动
调到可学区间。**

### 2.2 学习率与权重尺度强耦合

| weight_scale | 脑区均值 | eligibility 最大 |
|---:|---:|---:|
| 0.5 | 0.043 | 0.0117 |
| 1.0 | 0.093 | 0.0314 |
| 2.0 | 0.178 | 0.0575 |
| 3.0 | 0.211 | 0.0940 |

资格迹近似线性放大 8 倍。也就是说 `learning_rate` 必须和 `weight_scale`
联合标定，否则规则要么惰性、要么饱和。这是设计缺陷，不是调参技巧。

### 2.3 没有信用分配

`docs/gomoku-protocol.md` 自己写明：通用资格迹**不是动作特定的**，
全局标量 RPE 门控所有边不构成合法 actor credit。实测后果：

- 输入污染型漂移（高斯噪声）：批量近似下 +32 个点（3/3 种子）；
- 结构型漂移（平移 2px）：3 个种子里 2 个直接崩到 0。

即：规则只能表达"全局增益/信噪比调整"，表达不了"空间重排"。

### 2.4 可塑性没有稳定性保障

批量近似下 η=0.001/0.002 有效，η≥0.005 就崩溃；崩溃时资格迹范数从 120
掉到 0.1（活动被压死）。引擎没有权重归一化、突触缩放或自适应学习率。

### 2.5 样本效率显著低于 BPTT

同任务、同架构（视网膜 + 稀疏核 + 线性读出）：

| 学习方式 | 预算 | 词准确率 | 字准确率 |
|---|---|---:|---:|
| 局部三因子（文档路线） | 2500×8 | 38.4% | 67.3% |
| BPTT | 8000×20 | 83.2% | 92.9% |

约 3 倍差距，方向符合预期（局部规则信息更少），但应写进文档而不是
被当作"脑不行"。

## 3. 评测协议风险

1. **子集口径**：2000 张子集上 99.99% 等价于 0 错误，换划分即可"达标"。
2. **标签噪声上限**：MNIST 测试集含标注错误，可用上限约 99.8%–99.9%；
   99.99% 在诚实口径下不可达。
3. **贡献归属**：99.58% 的模块构成是前端约 200k 参数、递归边 2,016 条、
   读出 2,570；递归步数消融的原始数据见
   `MNIST_OPTIMIZATION_RESULTS.md` §6。
4. **训练方式未标注**：91.1% / 96.4% / 99.58% 全部是 BPTT；
   38.4% 是局部规则。两者不可混排。

## 4. 工程环境问题

1. `.venv` 里是 **CPU-only torch**，CUDA 只在系统 Python 3.13
   （`2.13.0.dev+cu132`）。不确认就会默认跑 CPU。
2. 5 种子集成本机在 CPU 上 **OOM**（第 4 个种子，6.4MB 分配失败），GPU 版正常。
3. PowerShell 直接给原生 exe 传 `--config-json` 会吞双引号，
   必须用 `subprocess.run([...])` 或配置文件。
4. **`.venv-str/` 未进 `.gitignore`**，有误提交风险。
5. 仓库工作目录没有 `.git`（是拷贝目录），今天才重建并接上远端。

## 5. 未被证伪的正向结论

1. **引擎单元不是缺陷**：把硬钳位换成平滑 soft-clamp 的对照臂，
   大预算下 38.4% → **6.6%**，差 5.8 倍。硬钳位带来的稀疏性有益。
2. **死区比例与尺度无关**（51.7% vs 51.2%），且不影响大预算学习能力；
   我之前"死区减半学习信号 ⇒ 底层缺陷"的推断**被否定**。
3. **项目路线可学**：视网膜 + 稀疏核 + 局部三因子 + 外部读出，
   2500 样本内到 38.4% 词准确率。
